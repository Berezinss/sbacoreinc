# SBA CORE GitHub Pages site

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and scroll animations
- `assets/` — image files

## Publish on GitHub Pages
1. Create a new public repository on GitHub, for example `sbacore-site`.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will give you a temporary URL like `https://USERNAME.github.io/sbacore-site/`.
7. Review the website there first. Do not change your sbacoreinc.com DNS yet.

## Custom domain later
Only after the GitHub Pages version is approved, add `sbacoreinc.com` under **Settings → Pages → Custom domain** and then update the DNS records at your domain registrar.
